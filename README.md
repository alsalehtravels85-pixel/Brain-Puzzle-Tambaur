# Tambaur Brain Puzzle 2048

Offline-first Android number puzzle game.

- 4x4 2048 gameplay
- Touch swipe and keyboard controls
- Score and locally saved best score
- Undo and new game
- Win and game-over states
- No account, API key, internet, ads, or analytics in v1.0

## Build
GitHub Actions builds a debug APK automatically on every push. Download it from the repository's Actions run → Artifacts.

Package: com.cybercity.brainpuzzle
